## 已实现

- `design.py`：120个候选正式场景、72/24/24划分、240个诱饵实例、240个固定呈现。45种诱饵组合各出现5--6次；按N×诱饵数×角色模板分层划分，各划分特征秩与可见特征重建通过。
- `estimation.py`：观测r的条件选择似然、只用z的识别logistic、训练集拟合和验证集正则选择、ρ约束、不惩罚β、五种响应模型、对r精确枚举的独立边缘预测、NLL/Top1/Brier/10箱ECE、配对场景bootstrap及Holm校正。
- 场景bootstrap在训练和验证划分内分别抽取整个场景。该场景的全部有效重复共享权重；每次重拟合两个阶段并重选正则强度。缺失响应不补造。没有识别标签变化或增广选择矩阵不满秩时，阻止输出虚假的ρ点估计。
- `precision.py`：8种生成条件，每种200组独立数据、每组2000次场景bootstrap的可续跑精度研究入口。默认只运行小规模流程检查，明确禁止将其标为正式精度通过。
- `analysis_smoke.py`：在有明确已知参数的合成数据上，运行五基线、独立测试预测和少量场景bootstrap，验证流程衔接。

正则选择规则：识别阶段按验证集Bernoulli NLL；选择阶段按验证集边缘NLL。训练阶段始终使用观测r；预测API不接受测试r。主拟合只用训练集，验证集用于调参，不将两者合并重拟合。β数值范围[-30,0]；下界敏感性尚待补齐。当前仅有主效应，无临时添加交互项。

## 检查和运行

```powershell
python _build/formal/test_estimation.py
python _build/formal/design.py
python _build/formal/analysis_smoke.py
python _build/formal/precision.py
```

上述命令均不调用接口。已有冻结输出若与新代码或配置不一致会拒绝覆盖；请使用新的`--out`目录。

完整精度研究是长期离线计算：

```powershell
python _build/formal/precision.py --run-full --out _build/formal/precision_full
```

完整研究包含3,200,000次场景bootstrap重拟合，加上原始拟合和每次验证集调参。默认小流程不能替代它。每个条件的200次重复需要报告覆盖率的蒙特卡洛误差；不能只看数值收敛。
